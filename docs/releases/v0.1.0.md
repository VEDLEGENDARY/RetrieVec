# RetrieVec v0.1.0 release candidate

Research papers become searchable evidence with reproducible snapshots, source
inspection and optional cited answers. Ask supports Answer and Find passages;
Sources manages ingestion; Saved research retains runs and provenance.

This candidate adds a local Keycloak/SciFact demo, explicit section filters,
identifier metadata, verified PDF glyph highlights and cited comparison tables.
Experimental reranking and fusion remain opt-in; ordinary ranking, consent,
authorization and snapshot immutability are preserved.

## Evidence and limits

- Complete SciFact/SCIDOCS retrieval experiments and paired intervals are in
  [BENCHMARKS.md](../../BENCHMARKS.md). Cross-encoder improvements on SciFact
  did not generalize to SCIDOCS; it is not a new default.
- [ANSWER_EVAL.md](../../ANSWER_EVAL.md) records 11 completed and 49 failed
  Qwen2.5 1.5B cases. These are synthetic-question, automatic-only results;
  semantic accuracy is unmeasured. NLI was NOT run; human review is blank.
- PDF highlights require exact glyph/text alignment. Unsupported layouts retain
  an explicit limitation. The demo contains abstracts, not original paper PDFs.
- Kubernetes deployment is not verified here: kubectl has no current context.
  Manual screen-reader and other-browser checks remain open.

This note does not publish a GitHub release or tag. Verification commands and
