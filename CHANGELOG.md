# Changelog

## Unreleased — paper workspace polish

- Paper-first welcome, clearer collection navigation, research-question starters,
  and an in-app guide with keyboard shortcuts and PDF advice.
- Browsable upload library with processing status, literal filename search,
  cursor pagination, and snapshot-checked original-source links.
- New collections open directly in Sources; finished uploads offer a search handoff.
- Full local application in the default Compose stack, Windows and POSIX startup
  launchers, workspace and identity readiness checks, and cached container builds.
- New installation and first-use guide. Database-only native development moves
  to `compose.database.yaml`; the starter stack keeps its existing volume names.
- Updated the transitive source-map dependency for
  [GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q).

## 0.1.0 — release candidate, 2026-10-05

This is a prepared release note, not a published release or tag.

- Unified Ask, Sources and Saved research with accessible shared controls,
  explicit generation consent and retained evidence inspection.
- Concurrent hybrid retrieval with verified ranking parity; opt-in fusion and
  cross-encoder experiments with frozen pools and paired confidence intervals.
- Synthetic answer evaluation through the real pipeline, blank human-review
  exports, optional automatic judge, and honest failure accounting.
- Opt-in section boundaries and filters, source-bound arXiv/DOI metadata,
  verified ordinary PDF highlights and cited paper comparison tables.
- Local Docker demo with Keycloak and a retained SciFact starter corpus.

Retrieval ranking, authorization, consent and immutable snapshot rules remain
unchanged. Section chunking and reranking remain opt-in. No human answer-quality
review or NLI evaluation is claimed. See [release notes](docs/releases/v0.1.0.md).
